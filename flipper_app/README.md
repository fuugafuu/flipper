# FZMV Player for Flipper Zero

Native `.fap` player for the `.fzmv` files produced by this repository's web converter.

## Installation

1. Build from this directory with `ufbt` against Flipper firmware SDK 1.5.1, or use the prebuilt `.fap` from `flipper_app/releases`.
2. Copy `fzmv_player.fap` to `SD Card/apps/Media/` on a Flipper Zero with compatible firmware.
3. Copy `.fzmv` movies to `SD Card/fzmv/` (other folders are accessible in the file picker).
4. Open **FZMV Player**, then choose the movie.

## Controls

| Button | Function |
| --- | --- |
| OK | Pause / resume; restart at end |
| Hold OK | Rename the current .fzmv file using the on-device keyboard |
| Left / Right | Seek backward / forward by 5 seconds |
| Up / Down | Speaker level, 0 to 100% |
| Back | Exit |

Paused playback shows the elapsed time and volume over the video frame.
Renaming pauses playback, keeps the `.fzmv` extension and current directory, and refuses to replace existing files. Files with non-ASCII names initially show `video` in the keyboard because the Flipper text keyboard is ASCII-oriented.

## FZMV format

The 64-byte header, absolute frame index, RLE-encoded frame records and 2-second intra-frame interval match `src/lib/format.ts`.

- **Video** 128×64, 1-bit MSB-first in source files, up to 60 fps. Each frame is either raw, RLE, XOR delta, or XOR delta + RLE. Forward playback reuses the decoded frame across skipped frames instead of repeatedly seeking back to a keyframe. The device converts it to the display's vertical-byte framebuffer. Playback may drop frames when SD or screen refresh cannot keep pace.
- **v1 audio** 20 ms tone records (frequency, gain, gate). Playback uses the official speaker API.
- **v2 audio** 16,000 Hz independently decodable 256-sample IMA ADPCM blocks (132 bytes each). Playback decodes blocks into a 2048-sample circular DMA buffer with 1024-sample halves, providing 128 ms of buffered audio, and drives the internal TIM16 PWM speaker output with TIM2 sample clock. The DMA playback position is the video clock. This requires access to TIM2 and DMA1 channel 1, used by third-party Flipper audio players and not reserved through a general-purpose Flipper audio API.

The sound is generated by the onboard piezo buzzer. v2 playback uses dynamic range compression to amplify quieter samples. v1 tones use the full requested speaker volume. Pulse-width-driven samples cannot guarantee hi-fi music fidelity. Physical loudness, timbre, audible artifacts, DMA compatibility with other firmware builds, and sustained 60 fps have **not** been validated on a Flipper Zero device. Build success only verifies SDK-level compilation and linking.

Memory use is bounded during playback, including SD streaming and random-access frame decoding. File integrity, frame offsets and ADPCM block layout are checked. A file's duration and its audio sample count may differ; silence follows the available audio samples.

## Build

```sh
cd flipper_app
ufbt
```

Expected output is `dist/fzmv_player.fap`. Verified locally with SDK release **1.5.1**, API **88.2**.
